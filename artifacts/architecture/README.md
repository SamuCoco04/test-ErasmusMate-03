# ErasmusMate — artifacts/architecture/

## Purpose

This folder contains architecture notes, proposals, and constraints for ErasmusMate.

Codex must inspect this folder before deciding architecture.

## Expected contents

- architecture proposals
- module boundaries
- API design notes
- previous architecture evaluations
- security and permission notes
- testing architecture
- map integration notes
- deployment notes if any

## Usage

If architecture is not fully specified here, Codex is expected to choose a maintainable architecture and record it in `DECISIONS.md`.

Any meaningful deviation from documented architecture must also be recorded in `DECISIONS.md`.
